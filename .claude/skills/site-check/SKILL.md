# 公開前チェック

## 1. 機械的なチェック

```bash
python3 .claude/skills/site-check/check.py
```

各ページについて、`lang`、`description`、`canonical`、`og:*` があるか、base64 の画像を埋め込んでいないか、サイト内リンクの行き先があるか、プロフィールが `noindex` のままか、を調べる。`ERROR` は直す。`WARN` は理由があれば残してよい。

```bash
python3 social/instagram.py check
```

Instagram の投稿文（`social/instagram/`）の画像の形式、縦横比、字数、ハッシュタグの数を調べる。`main` に入ると投稿されるので、`ERROR` は必ず直す。

## 2. 表示のチェック

変えたページを、スマホ幅（375px）とPC幅（1280px）の両方で見る。

```bash
python3 -m http.server 8000 >/dev/null 2>&1 &
```

Playwright のスクリーンショットを撮って目で確かめる。クラウド環境では Chromium が `/opt/pw-browsers` に入っている。

- 見出しが1〜2文字だけ次の行に落ちていないか
- 横スクロールが出ていないか
- 電話番号やボタンが指で押せる大きさか

## 3. 日本語トップと英語トップ

`index.html` を変えたら、`en/index.html` にも同じ変更がいるかを確かめる。構成と事実を揃える。文言は直訳しなくてよい。

## 4. 個人情報

`git diff` を読んで、`CLAUDE.md` の「書くときのルール」から外れていないかを見る。サイトにすでに載っている経歴のほかに、代表の個人的な情報や、区より細かい住所が増えていたら止めて、本人に確かめる。コミットメッセージとPR本文も同じように見る。
