    手順 note を開く
    1. note で「投稿」→「テキスト」を開く。
    2. 下の「タイトルをコピー」を押して、タイトルの欄に貼る。
    3. 「本文をコピー」を押して、本文の欄に貼る。見出しが普通の文字になったら、その行を選んで見出しにする。
    4. 見出し画像とタグを入れて、公開する。
