紅葉の日の1日モデルコース2本。東山の日と嵐山の日

時刻で空き、電車でつなぐ。秋の京都シリーズの2本を合わせた、東山を歩く日と嵐山から始める日の1日コース。

2026.09.25 秋の京都 03 Daichi Ninomiya

紅葉の季節の京都は、時刻で空き、電車でつなげます。前の2本の記事で書いたこの2つを合わせて、1日のコースを2本組みました。東山を歩く日と、嵐山から始める日です。どちらも、名所は朝と夜に回し、昼は広い場所で過ごします。

私は京都市下京区で生まれ、24歳までこの街で過ごしました。6年離れて、30歳で戻ってきました。

紅葉の日に、1日を失う3つのこと

1. 京都駅からバスに乗る
紅葉の季節の昼前は、京都駅のバス乗り場がいちばん長い列になります。乗れても道が混んでいて、着く時刻が読めません。

2. 昼に東山の坂へ行く
清水寺へ上る坂は、昼には人の列の中を歩く道になります。同じ坂が、朝7時にはほとんど人のいない道です。

3. 12時に昼ごはんを探す
観光地の近くの店は、12時台にどこも並びます。11時前に入るか、14時以降にずらすだけで、待つ時間が大きく変わります。

2本のコース

どちらも、移動は電車と徒歩が中心です。京都駅の近くに泊まる前提で組んでいます。

A 東山コース（初めての京都に）
清水寺 → 産寧坂・二年坂 → 八坂神社 → 東福寺 → 南禅寺 → 岡崎・平安神宮 → 永観堂（夜）

B 嵐山コース（2回目の京都に）
竹林の道 → 天龍寺 → 常寂光寺 → 渡月橋 → 京都御苑 → 鴨川 → 清水寺（夜）
